================================================================
  Velo 语言 1.0  ——  快速开始
================================================================

Velo 是一门「语法像 Python、运行速度像 C」的编程语言。
你写的是类 Python 源码，编译出来的是原生机器码。

----------------------------------------------------------------
一、最快的用法
----------------------------------------------------------------

1. 按 Win+R，输入 cmd，回车（打开命令行窗口）
2. 依次输入下面三行（每条按一次回车）：

   cd /d "%USERPROFILE%\Desktop\Velo"
   veloc.exe run examples\hello.velo

屏幕上会输出：

   Hello, Velo!
   1 + 2 = 3
   你好，世界！

这就完成了第一次「编译 + 运行」。

----------------------------------------------------------------
二、自己写一个程序
----------------------------------------------------------------

在本文件夹里新建一个文本文件，改名成 my.velo，写入：

   def main() -> int:
       var n = 10
       var total = 0
       for i in range(n):
           total += i * i
       println("前 {n} 个平方和 = {total}")
       return 0

然后在命令行里运行：

   veloc.exe run my.velo

想生成一个可以双击的 exe：

   veloc.exe build my.velo
   my.exe

----------------------------------------------------------------
三、常用命令
----------------------------------------------------------------

   veloc.exe run   文件.velo     编译并立即运行（开发时最常用）
   veloc.exe build 文件.velo     生成 exe 文件
   veloc.exe check 文件.velo     只检查语法和类型，不生成程序
   veloc.exe emitc 文件.velo     把生成的 C 代码导出来看
   veloc.exe env                 查看编译器后端信息
   veloc.exe help                显示全部用法

   build 常用选项：
     -o 名字.exe     指定输出文件名
     --fast          激进优化（需要较新的 CPU）
     --debug         调试版，关闭优化

----------------------------------------------------------------
四、示例程序

----------------------------------------------------------------
六、性能速览
----------------------------------------------------------------

   同一算法、同一机器、同为原生程序：

     测试              Velo      C        Python 3.13
     fib(34)           0.050s    0.047s   1.448s
     埃氏筛 10^7       0.074s    0.069s   4.929s
     曼德博 800x800    0.083s    0.076s   11.177s
     200万次追加+排序  0.216s    0.201s   1.977s

   → Velo 的运行时间是等价 C 程序的 1.07 倍左右，
     比 Python 快 9 到 134 倍。

----------------------------------------------------------------
七、注意
----------------------------------------------------------------

* 请勿单独移动 veloc.exe：它需要同目录的 python313.dll 和 runtime\ 文件夹。
* 编译需要电脑上装有 Visual Studio 的 C++ 工具（本机已具备）。
* 如果提示找不到 MSVC，可设置环境变量：
      set VELO_VCVARS=...\vcvars64.bat
  具体路径见 docs 里的手册第 5 章。

祝用得开心。
